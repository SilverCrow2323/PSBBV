01 / Product brief

NOT JUST ANOTHER ICON GRID.

PSBBV takes the channel-first spirit of PlayStation Broadband Navigator and gives it a native Vita home. Familiar DNA. New body. No pretending the unfinished bits are magic.

Native applicationIndependent homebrewOffline-first shell
The actual pitch

A PlayStation environment, not a wallpaper with buttons.

PSBBV is meant to feel like a connected entertainment space. The channels are destinations, not decorative tiles.

🧭

Navigator, not launcher

Home is the entrance. Each channel should eventually have its own context, content and useful actions.

🧬

Heritage without cosplay

PSBBN informs the structure and spirit. PSBBV gets its own visual system, interaction model and technical limits.

📴

Useful offline

The shell and local experiences must not fall apart because Wi‑Fi disappears or a remote service has a bad day.

🧾

Honest by design

Planned, unavailable and implemented are different states. The UI must say which one you're looking at.

Channel lineup / proposed

Six doors. One house.

These are product areas, not six claims that everything is already working.

🎮

Games

Local collection discovery, metadata, favourites and safe shortcuts—subject to the platform APIs actually available.

Planned
🛠️

Applications

Installed homebrew and utilities, with a catalogue that knows the difference between installed and merely interesting.

Planned
🌐

Network

Connectivity state and optional community services. No fake servers, pretend logins or invented status lights.

Planned
🎧

Media

Local media entry points. Codec and playback promises come only after library and performance checks.

Planned
📦

Downloads

Transfer tasks, progress and completed items, with real data and recoverable errors.

Planned
⚙️

System

Device information and PSBBV preferences. The Vita system shell stays the Vita system shell.

Planned
First milestone / acceptance

What “foundation complete” actually means.

🛑
Not a replacement shell

PSBBV is an application. It does not replace LiveArea, modify firmware, reimplement proprietary Sony services or ship copyrighted games, media or firmware.
