## ✨ Included in this candidate

- Native Vita application shell using C++17, VitaSDK, CMake and libvita2d.
- 960 × 544 landscape rendering baseline.
- D-pad, Cross, Circle and Start application-menu navigation.
- Front touchscreen application-menu interaction with edge-triggered activation and tested hitbox gaps.
- About and Exit menu actions.
- Six stable node identities and a versioned manifest/schema contract.
- Bounded manifest parsing with capability/permission validation and negative fixtures.
- Pure node lifecycle transition policy and allocation-free NodeJob state policy.
- Read-only Games catalogue/discovery foundation compiled as a dependency, but not exposed as an openable channel.

See the [workflow jobs](https://github.com/SilverCrow2323/PSBBV/actions/runs/44895995146) and the [hardware test record](../TESTING.md). The candidate-manifest provenance guard is also unit-tested to reject mixed commits, runs, artifacts and digests.

## 🚧 Not included / known limitations

- Games, Applications, Network, Media, Downloads and System are still PLANNED registry entries; none is an openable Core destination.
- Games discovery is not a released user-facing channel; launching games is not implemented.
- NodeJob does not yet schedule work or deliver results to the UI thread.
- No dynamic third-party node loader is included.
- `SCBV00001` is provisional and has not been checked against the user's installed titles.
- The exact candidate has not been installed or validated on a physical PS Vita.
- Suspend/resume, physical controls, touch feel, frame pacing, memory use and shutdown remain hardware gates.

## 🕹️ Required device validation

Before this candidate can become a stable 0.1.0 release, install this exact artifact on a physical Vita and record:

1. Vita model, firmware and homebrew environment.
2. Extracted VPK SHA-256 and Title ID conflict check.
3. LiveArea appearance, install and first launch.
4. Shell rendering, application-menu controls and touch hitboxes.
5. About/Resume navigation and clean shutdown.
6. Suspend/resume, frame pacing and extended-session memory behavior.

Do not report CI success as hardware compatibility.

## Release decision

This candidate is deliberately **not tagged and not published**. The machine-readable record is [v0.1.0-rc.1-manifest.json](v0.1.0-rc.1-manifest.json). It keeps `official_release: false` and hardware acceptance pending.

The stable release remains blocked on the exact-device report, final Title ID confirmation and completed hardware gate.
