THE DOCS DESERVE DAYLIGHT.

The field guide is a static site. One repository setting lets GitHub Pages publish the docs folder whenever the project is updated on main.

Open Pages settings ↗Back to the guide

One-time setup

Flip the switch. That's the whole ritual.

This cannot be preconfigured through the current repository connection. It takes one manual setting in GitHub.

1️⃣

Open repository settings

Go to Settings → Pages in SilverCrow2323/PSBBV.

2️⃣

Choose GitHub Actions

Under Build and deployment, set Source to GitHub Actions and save.

3️⃣

Merge to main

The SPDW Documentation workflow runs when the docs or workflow changes reach main.

4️⃣

Check the deployment

Open Actions and confirm the Pages deployment completed successfully.

Preview before publishing

Want to check the site locally?

python3 -m http.server 8000 --directory docs

Open the local server address printed by Python and browse the index page. The portal uses local CSS, JavaScript and SVG assets. No external frontend framework is required.

⚠
Publishing does not certify the product

A hosted manual does not mean PSBBV is a release. Channel features, VPK installation, suspend/resume and real hardware checks retain their own acceptance gates.
